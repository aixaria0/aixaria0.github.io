02 / RECOVERY SCENARIO

Crash the worker. Preserve the evidence.

The actual demo intentionally kills worker-2, records failure, restarts the same identity, retries the task and verifies the returned evidence before completion.

RECOVERY CONTRACT

Identity continuity matters.

A restart is not treated as success because a new process appeared. The runtime checks stable per-worker signing identity and journals the transition path.
