03 / INVARIANT ENGINE

Security becomes a threshold.

Each invariant binds one asset, one metric and one explicit threshold. A violated invariant is not a warning label; it can become a CI failure condition.

INV-DATA-PROV

Data provenance remains trustworthy.

provenance≥ 0.80

Training and retrieval inputs require attributable lineage.

INV-MODEL-INTEGRITY

Promoted model integrity remains high.

integrity≥ 0.90

Critical model artifacts must remain identical to approved artifacts.

INV-AGENT-SURFACE

Runtime attack surface remains bounded.

attack_surface≤ 0.50

Agent privileges and ingress paths must stay bounded.

integrity≥ 0.90
