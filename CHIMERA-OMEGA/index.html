01THESIS
“No evidence, no claim.
Verification is not a boolean.”

OMEGA’s core is deliberately narrow: compare every supplied observed state-commitment sequence against an expected sequence inside a pinned evidence package.

A match supports that artifact-level proposition only. Formal proof, implementation binding, runtime reproduction, independent observation, production reachability and finality remain separate dimensions.

04LIMITS

THE EPISTEMIC FIREWALL

What OMEGA can say
versus
what it refuses to imply.

A

SUPPORTED
WHEN EVIDENCED

  1. Artifact integrity

    Selected bytes match the selected digest.

  2. Claim / target binding

    Evidence belongs to the exact reviewed context.

  3. Provenance structure

    Duplicate, dangling and cyclic references fail closed.

  4. First divergence

    The earliest supplied mismatch can be surfaced.

  5. Policy-local authorization

    Only when separately pinned policy supports it.

B

NOT IMPLIED
WITHOUT SEPARATE EVIDENCE

  1. External truth

    Correct bytes can still describe a false world.

  2. Independent observation

    Separate process does not equal independent authority.

  3. Production reachability

    Offline replay does not establish deployment.

  4. Consensus finality

    A local verifier is not network-wide finality.

  5. Formal proof

    Deterministic tests are not a theorem.

05PROTOCOL

The OMEGA loop is a sequence of refusals.

Each phase removes ambiguity. None is allowed to manufacture authority for the next.

01

SELECT

Define the exact claim, target, assumptions and obligations.

02

PIN

Choose source, context, policy, binary and evidence identities externally.

03

SEAL

Bind content-addressed evidence and provenance into a deterministic package.

04

VERIFY

Recompute the bounded predicate instead of trusting producer labels.

05

ATTACK

Run negative controls and preserve the first failure boundary.

06

REPORT

Return supported, contradicted, rejected or insufficient—never more.
