01 / Verification Kernel

Evidence moves through gates.

OMEGA does not promote a claim because one hash, signature, replay, or quorum looks convincing. Each predicate stays separate and each unsupported dimension stays explicit.

COMPUTED

UNKNOWN

04 / Epistemic Boundary

What OMEGA refuses to fake.

The project is intentionally strict about the difference between evidence integrity and authority, between reproducibility and truth, and between a useful local result and a universal claim.

What the kernel can establish

Bounded claim/evidence binding, provenance structure, content-addressed artifact integrity, supported local semantics, deterministic comparison, first divergence, and selected negative controls.

What it does not magically establish

External truth, organizational independence, physical-world validity, production reachability, consensus finality, trusted execution, or complete source-to-binary equivalence without separate evidence.
