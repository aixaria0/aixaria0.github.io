05 / CLI SEMANTICS

Four exits. Four meanings.

OMEGA's process result carries semantics instead of compressing every outcome into success/failure.

0SUPPORTED

Bounded artifact predicate is locally supported, or a narrowly scoped binding is confirmed.

1CONTRADICTED

A structurally valid artifact contradicts the predicate or report replay diverges.

2REJECTED

Input, policy, provenance, integrity, signature, authorization, pin or I/O boundary fails.

3INSUFFICIENT

Package is valid but evidence or controls cannot support the requested proposition.

06 / OMEGA LOOP

Verification as a disciplined refusal.

Every stage narrows the claim. None grants itself authority.

01SELECT

02PIN

Choose source, context, policy, binary and evidence identities externally.

03SEAL

04VERIFY

05ATTACK

Run negative controls and preserve the first failure boundary.

06REPORT

Return supported, contradicted, rejected or unknown—never more.
